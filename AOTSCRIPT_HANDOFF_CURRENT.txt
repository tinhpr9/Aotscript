PRODUCT_GOAL
- Hoàn thiện AOT Group Control: tool đồng bộ thao tác từ máy reference sang máy follower theo chuỗi:
  reference thực hiện hành động -> relay/Worker chuyển hành động -> follower thực hiện tương ứng -> ACK/status xác nhận.
- Reference hiện tại: m37.
- Follower hiện tại: m117.
- App acceptance hiện tại: org.swiftapps.swiftbackup (Swift Backup).
- Mục tiêu không chỉ là một E2E pass; mục tiêu là cơ chế đồng bộ ổn định, đúng foreground/UI state, selector/coordinate/action, fingerprint/precondition, relay/ACK và runtime lifecycle.

CHUYÊN MÔN TRỌNG TÂM
- Android Activity/Task lifecycle, foreground/resumed state.
- dumpsys activity/window và View Hierarchy.
- UI hierarchy parsing, semantic selector/resource-id, coordinate mapping, fingerprint/precondition.
- Timing/race giữa launch, focus, snapshot và action.
- Reference/follower action replication, relay/WebSocket, ACK/status, dedupe/out-of-sync guard.
- Runtime lifecycle và acceptance E2E.

BLOCKER VỪA ĐÓNG
- Lỗi trước đây: m117 trả m117_fingerprint_mismatch tại bước NAV_CLOUD.
- Causal chain đã được chứng minh:
  1. Swift Backup thật sự là mResumedActivity trên m117.
  2. dumpsys window windows trên m117 có thể rỗng hoặc giữ launcher stale ginlemon.flowerfree.
  3. foreground_package() cũ phụ thuộc window focus nên có thể chọn sai package.
  4. dump_ui_xml() vì thế có thể chọn sai View Hierarchy.
  5. Follower thực thi action nhưng after_fingerprint khác reference.
- Fix đã thêm logic xác định package từ topResumedActivity/mResumedActivity trước, dùng window focus làm fallback.
- Selftest đã bổ sung các case stale launcher, missing focus, multi-activity hierarchy, ambiguous resumed state và fallback.
